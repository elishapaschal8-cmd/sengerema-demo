This folder holds the demo visuals for the Sengerema rural electrification demo.

IMPORTANT: These images are "Representative project imagery" and should NOT be presented as actual in-person project photos of Sengerema unless verified. Label the website images with one of these captions: "Illustrative visual" or "Representative project imagery".

Licensed images guidance:
- Prefer Unsplash, Pexels for high-quality royalty-free images. They generally allow commercial use without attribution, but always confirm the source license and any model/property release for images with people.
- Wikimedia Commons images often have explicit Creative Commons licenses and attribution requirements — check the license before use.

How to use:
1. Use the exact prompt files to search Unsplash/Pexels/Wikimedia or to run through an external image-generation service (Midjourney, Stable Diffusion). Do not feed these prompts to Copilot's image generation. Copilot is not an image generator.
2. Download images that match the prompt and the consistent visual identity (Tanzania, engineering, professional, realistic, premium).
3. Save each downloaded image with the exact filename used by the site (see list above).
4. Add a small caption near the image on the website: "Representative project imagery" or "Illustrative visual".

If you want, run the included recommended search queries in Unsplash/Pexels and copy the final image URLs into this README for reference.
